# 私有跨端同步准备

当前项目只有公开前端连接，未取得数据库建表管理权限；迁移尚未执行，自动同步未接通。

1. 在你自己的 Supabase 项目 SQL Editor 中执行 `migrations/20261026_private_sync.sql`。
2. 不要把服务密钥、数据库密码或访问令牌贴进聊天或网页。
3. 建表后仍需接入 Supabase Auth，并用两个账号验证数据隔离、并发合并和断网重试，才能启用自动同步。
4. 现在可以在网页“本机历史记录”中导出JSON，在另一设备同彩种下导入；默认只合并历史，勾选后才覆盖筛选。

不能为了让旧代码运行而允许匿名写入私人筛选或历史；旧代码的全局 `lot_type` 同步接口已停用。
